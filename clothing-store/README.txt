GRANUM — Демо-шаблон интернет-магазина одежды
=============================================

Статический frontend-шаблон современного интернет-магазина
одежды. Тёмная тема, минималистичный дизайн 2026.

Технологии: HTML + CSS + Vanilla JS
Без внешних зависимостей, CDN,  фреймворков.

Страницы:
---------
1. index.html      — Главная: hero, категории, новинки, хиты, предзаказ, преимущества
2. catalog.html    — Каталог: фильтры, 24 товара, сортировка, сетка/список, пагинация
3. product.html    — Карточка товара: галерея, размер, цвет, табы, отзывы, похожие
4. profile.html    — Профиль: данные, заказы, адреса, избранное, уведомления, настройки
5. wallet.html     — Кошелёк: баланс, бонусы, промокоды, история операций
6. feedback.html   — Обратная связь: форма, FAQ, контакты
7. cart.html       — Корзина: товары, промокод, доставка, оформление
8. preorder.html   — Предзаказ: как это работает, товары, быстрая заявка
